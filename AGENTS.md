# This project is pinned to Expo SDK 54

Xcode 16.2 on this Mac (macOS 14.7.8) ships Swift 6.0. Expo SDK 57 requires Swift 6.2, which needs
Xcode 26 / macOS 15+. Rather than upgrade the OS, the project is pinned to SDK 54 / React Native 0.81.

Read the versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code - not
latest, and not v57. See decisions.md in the ai-app-build second_brain project for the full reasoning.
